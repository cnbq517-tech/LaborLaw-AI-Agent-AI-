# 鸿蒙 7 复赛版更新说明

## 2026-10-22 更新

本次更新集中在稳定性、聊天记录和法条引用体验，全部改动位于 `harmony-app`。

### 稳定性与性能

- **本地检索移到后台线程**：52MB 法规索引的解析和每次提问的检索都放到常驻 Worker（`workers/KnowledgeWorker.ets`）中完成，界面线程只负责读取文件并把数据整块交给 Worker，不做复制。检索打分规则保持不变，结果与之前一致。
- **检索提速**：每份文档的小写标题、规范化标题、地区等字段改为加载时计算一次。此前每次查询都要对 5 万多个文本块重复执行正则规范化。
- **流式回答**：普法咨询、案件梳理和卷宗报告改为边生成边显示（SSE），并提供「停止生成」，已生成的内容会保留。服务若不支持流式、直接返回普通 JSON，同样能正常处理。

### 聊天记录

- **对话与卷宗本机保存**：普法对话、案件对话、卷宗六项内容和分析报告保存到应用沙箱（`ChatStateStore.ets`）。应用被系统回收后重新打开会自动恢复。写入经过临时文件再替换，避免中途崩溃留下损坏的文件。
- **历史咨询侧边抽屉**：普法页每轮问答结束后自动归档，最多保留 50 段，每段保留最近 100 条消息。抽屉按「今天 / 昨天 / 近 7 天 / 更早」分组，支持搜索、左滑删除，并高亮当前对话。
- **打开方式**：点击标题栏菜单按钮，或在普法页上从左向右滑动打开。屏幕最边缘留给系统返回手势，所以页面上任意位置右滑都可以拉出抽屉；关闭可以点遮罩、向左拖动或用系统返回。
- **标题栏按钮**：菜单按钮和返回首页按钮在标题栏展开时位于金色短线下方，收起后移到标题左侧，位置随滚动平滑过渡。
- **对话时间**：只有发送新消息才更新对话时间。切换对话或返回首页不再改动时间和排序。
- **清空记录**：设置页新增「本机记录」卡片，可确认后清空全部对话、历史与卷宗。

### 法条引用

- **可点击的引用标签**：回答中的 `[K1]` 显示为金色数字标签，点击后从底部弹出法条卡片。卡片包含法规名称、条号、效力状态（现行有效 / 已失效 / 尚未生效 / 已被修订 / 未标注）、施行日期、条文原文和来源文件，可左右切换其他依据。
- **高亮被引用的句子**：卡片会尽量在原文中高亮被引用的那句话。模型改写措辞导致找不到相同片段时，只显示原文、不高亮。
- **适用范围**：普法回答、案件回答、正在生成的回答、卷宗报告以及历史对话都可以点击。从报告中打开的法条卡片关闭后会回到报告。

### 视觉与主题

- **光感效果**：抽屉使用毛玻璃底加 HDS 点光源（`hdsEffect.pointLight`）。手指在抽屉上滑动时，金色光晕跟随手指移动，交互方式与悬浮导航栏一致。
- **组件材质说明**：测试设备（HarmonyOS 7.0.0.109）报告支持 `ImmersiveMaterial`，但组件级 `systemMaterial` 渲染为透明，因此抽屉没有采用组件材质。底部面板仍使用系统材质。
- **主题切换时图标同步变色**：通用图标组件改为按引用传参。此前 `@Builder` 按值传参，图标颜色会停留在应用启动时的主题，浅色模式下部分图标显示为黑色。
- **浅色模式图标底色**：「先把情况告诉我」和「本地法规库」的图标在浅色模式下改为浅色底。

## 新增与改进

- **升级目标 API 26**：使用 DevEco Studio 26 和鸿蒙 7 SDK 构建。
- **全新视觉与双主题**：正义蓝与鎏金配色、线性图标、跟随系统/浅色/深色外观，统一启动背景及桌面卡片视觉。
- **沉浸光感交互**：悬浮导航自适应材质、选中高光、轻量按压反馈；滚动头图平滑收缩；附件、法规依据和报告使用统一底部面板；支持减少动效。
- **维权材料闪控窗**：跨应用显示六项材料的完成状态，可返回案件继续填写；支持深浅主题和窗口大小适配。打开后按钮同步显示状态；窗口不展示姓名、工资和案情正文，不读取其他应用内容。
- **互动桌面卡片**：保留欠薪、未签合同、违法解除、加班四个入口；新增预设普法提示及“了解更多”；接入 `LiveFormExtensionAbility` 和摇一摇触发的天平展开动效。
- **咨询体验优化**：紧凑输入栏、加号附件入口和发送箭头；发送后收起键盘，键盘弹出时隐藏导航；增加返回普法首页入口并适配主题。
- **案件信息反馈**：完整度环与文本百分比同步；六要素芯片反馈填写状态；报告生成显示实际处理阶段。

## 保留的基础能力

普法与案件多轮咨询、六要素卷宗、结构化报告、TXT/MD/DOCX 材料读取、法规来源及引用校验、用户配置的模型 API 直连、Asset Store 本机密钥保存继续保留。
内置资料 2790 份，其中 2761 份可检索，离线索引含 52903 个文本块；资料未经全面效力审查，使用时仍需核对官方最新文本。

## 运行与限制

- 构建入口见 [构建与签名说明](../harmonyos-build.md)。公开配置不含个人签名及本机路径，构建默认生成未签名 HAP。
- 闪控窗需要受支持的鸿蒙 7 设备、用户授权及包含 FLOAT_VIEW ACL 的签名 Profile。权限未获批时，普通签名包可能无法安装。
- 摇一摇需要系统互动卡片支持；省电模式可能拦截动效。不支持时保留普通卡片入口。
- 本轮以手机真机为验收范围，未新增平板双栏。外观选择重启后的行为以当前实现为准。
- 本次上传源码与开发文档，不包含调试签名、HAP、个人报名材料或聊天数据。
