# 鸿蒙 7 复赛版更新说明

源码整理发布：2026-10-21。本版对应 2026-09-29 已完成真机演示的功能版本。

## 新增与改进

- **升级目标 API 26**：使用 DevEco Studio 26 和鸿蒙 7 SDK 构建。
- **全新视觉与双主题**：正义蓝与鎏金配色、线性图标、跟随系统/浅色/深色外观，统一启动背景及桌面卡片视觉。
- **沉浸光感交互**：悬浮导航自适应材质、选中高光、轻量按压反馈；滚动头图平滑收缩；附件、法规依据和报告使用统一底部面板；支持减少动效。
- **维权材料闪控窗**：跨应用显示六项材料的完成状态，可返回案件继续填写；支持深浅主题和窗口大小适配。打开后按钮同步显示状态；窗口不展示姓名、工资和案情正文，不读取其他应用内容。
- **互动桌面卡片**：保留欠薪、未签合同、违法解除、加班四个入口；新增预设普法提示及“了解更多”；接入 `LiveFormExtensionAbility` 和摇一摇触发的天平展开动效。
- **咨询体验优化**：紧凑输入栏、加号附件入口和发送箭头；发送后收起键盘，键盘弹出时隐藏导航；增加返回普法首页入口并适配主题。
- **案件信息反馈**：完整度环与文本百分比同步；六要素芯片反馈填写状态；报告生成显示实际处理阶段。

## 保留的基础能力

普法与案件多轮咨询、六要素卷宗、结构化报告、TXT/MD/DOCX 材料读取、法规来源及引用校验、用户配置的模型 API 直连、Asset Store 本机密钥保存继续保留。
内置资料 2790 份，其中 2761 份可检索，离线索引含 52903 个文本块；资料未经全面效力审查，使用时仍需核对官方最新文本。

## 运行与限制

- 构建入口见 [构建与签名说明](../harmonyos-build.md)。公开配置不含个人签名及本机路径，构建默认生成未签名 HAP。
- 闪控窗需要受支持的鸿蒙 7 设备、用户授权及包含 FLOAT_VIEW ACL 的签名 Profile。权限未获批时，普通签名包可能无法安装。
- 摇一摇需要系统互动卡片支持；省电模式可能拦截动效。不支持时保留普通卡片入口。
- 本轮以手机真机为验收范围，未新增平板双栏。外观选择重启后的行为以当前实现为准。
- 本次上传源码与开发文档，不包含调试签名、HAP、个人报名材料或聊天数据。
